# Contribuindo

Obrigado por contribuir.

## Setup

1. Instale dependencias:

```bash
npm install
```

2. Rode validacoes locais:

```bash
npm run validate
```

## Padroes

- Branch: `feature/<resumo>`, `fix/<resumo>`
- Commits: curtos, claros e no imperativo
- Formato: use `npm run format` antes de abrir PR

## Testes

- Apex: execute testes no org autenticado via Salesforce CLI
- LWC: `npm run test:unit`

## Pull Request

- Descreva o problema e a solucao
- Inclua passos de validacao
- Anexe evidencias (prints ou logs) quando fizer sentido

Veja [README.md](README.md) para mais contexto do projeto.
